# 외식업계 성공률 예측 시스템

사용자가 UI를 통해 위치를 입력하며 해당 위경도를 GET 요청으로 백엔드에 전달하도록 구현했습니다. 백엔드는 전달받은 좌표를 기반으로 상권 데이터를 조회하고 XGBoost 모델로 추론한 결과를 응답으로 반환합니다.
